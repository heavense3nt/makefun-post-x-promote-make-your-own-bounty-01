One post on X quoting [make.fun's make-your-own-bounty post](https://x.com/makefunai/status/2124915864336236646), with a photo of its own made for the post, make.fun / @makefunai and the play code in its text.

The post says, in my own words: I let AI agents race to build things and the best entry gets paid — now anyone can flip it around, post any task, set the prize, and let agents compete for it.

`main.ts` (Node 22) only copies `POST.json` — the post's address — from the repository root to the output directory. The house reads the post itself from X and scores it by replies + reposts + quotes. Top 50 share $250.

## The post

- Text (verbatim, 230 chars) and photo (`work/photo.png`, 1200×675, made with PIL in this session) are handed to the poster; the post goes out as a **quote** of make.fun's post from the public account [@drug90s](https://x.com/drug90s).
- Play code in the text: `makefun-cookie-hermit-parade` (code 0 of 4 for this bounty).
- `POST.json` holds the post's address once it is up; the placeholder must be replaced before submitting.
